# Marvia — сборки

Здесь лежат готовые бинарники панели и ноды. Исходники в этом репозитории не
публикуются.

## Установка панели

Нужен чистый сервер с Linux (amd64 или arm64) и домен, нацеленный A-записью на
него.

```
curl -fsSL https://github.com/jytt8u/marvia-releases/releases/latest/download/install-panel.sh -o install-panel.sh
sh install-panel.sh --domain панель.твой-домен --email ты@почта
```

Скрипт сам определит разрядность сервера, скачает ядро, сверит контрольную
сумму, поставит службу и получит сертификат Let's Encrypt. В конце напечатает
админский токен — **один раз**, сохрани его сразу.

Компилятор не нужен.

## Ноды

Скачивать для них ничего не надо: панель выдаёт готовую строку установки, и
бинарник нода забирает у неё же.

## Контрольные суммы

В каждом релизе есть `SHA256SUMS`. Установщик сверяет их сам; если хочешь
руками:

```
sha256sum -c SHA256SUMS
```

## Если github.com не открывается с сервера

Так бывает у хостеров в Иране и Китае. Скачай архив на машину, с которой
открывается, распакуй рядом со скриптом и поставь оттуда:

```
sh install-panel.sh --domain панель.твой-домен --bin-dir .
```
